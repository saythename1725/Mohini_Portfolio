Multilingual VoiceOps Support Agent

GitHub Repository

  • Gemini Embeddings
  • ChromaDB
  • Ollama

A multilingual customer-support voice agent designed to answer questions from policy documents and carry out approved support actions. The project brings speech, retrieval and tool execution into one end-to-end workflow across English, Hindi and Hinglish.

  • Policy-grounded answers: Retrieves relevant policy sections so responses can be traced back to supporting evidence.
  • Voice interaction: Connects speech-to-text and text-to-speech using Gnani Speech APIs for English, Hindi and Hinglish conversations.
  • Controlled tool execution: Includes caller verification before sensitive order lookups or support-ticket escalation.
  • Evaluation: Includes 52 policy test cases and 23 multi-turn dialogues to assess answer quality, retrieval and tool behaviour.

Focus: grounded answers, safe actions and measurable evaluation — not just a chat interface.
